# Security Policy

This repository is a **reference control plane** for crop-compliance observations,
field-review triage, and buyer-safe packet posture across AgriTech workflows. It
ships synthetic, non-sensitive sample data only. It is not a production system
of record and should not be deployed with real grower, buyer, export, or
program-review records without independent security review.

## Supported versions

Only the latest tagged release is supported for reference use.

## Reporting a vulnerability

Please use GitHub Security Advisories for private disclosure:

- [Open a security advisory](https://github.com/mizcausevic-dev/crop-compliance-observation-ledger/security/advisories/new)

If you cannot use advisories, open a private security issue through the
repository security tab when available.
